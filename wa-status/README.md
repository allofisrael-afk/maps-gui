# wa-status — עדכוני סטטוס לוואטסאפ

כלי חד-כיווני ששולח ל"הודעה לעצמי" בוואטסאפ עדכונים קצרים על משימות ש-Claude Code מבצע בריפו. הכלי רק שולח: אין בו קבלת הודעות ואין בו שליטה מרחוק.

## התקנה בריפו חדש (3 צעדים)

1. **מעתיקים** את התיקייה `wa-status/` לשורש הריפו, ומתקינים את הספרייה (פעם אחת לכל מחשב):
   ```
   python -m pip install neonize==0.12.4
   ```
2. **מתחברים** (פעם אחת לכל ריפו):
   ```
   python wa-status/wa_status.py setup
   ```
   הכלי פותח תמונת QR ושומר אותה ב-`wa-status/state/qr.png`. בטלפון: וואטסאפ > הגדרות > מכשירים מקושרים > קישור מכשיר, וסורקים.
   - ה-QR מתחלף כל 20 עד 60 שניות. אם הסריקה נכשלת, פתחו מחדש את `qr.png`. תצוגת התמונה של VS Code מתרעננת לבד.
   - חלופה ל-QR: ממלאים `phone` ב-`config.json` ומריצים `setup --code`, ואז מקלידים בטלפון את הקוד בן 8 התווים, דרך "קישור עם מספר טלפון".
3. **מדביקים** את התוכן של `CLAUDE_SNIPPET.md` לתוך `CLAUDE.md` של הריפו.

## פקודות

| פקודה | מה עושה |
|---|---|
| `setup` | התחברות ראשונה (QR) והודעת אימות |
| `send --type start\|done\|error\|blocked\|progress --msg "טקסט"` | שליחת עדכון |
| `summary --since 3h` | סיכום מ-`git log` לחלון זמן (`90m`, `3h`, `2d`) |
| `daily` | סיכום יומי מחצות (ל-Task Scheduler) |
| `check-interval` | מדפיס `yes` אם עבר מרווח העדכון המחזורי, אחרת `no` |
| `test` | הודעת בדיקה (בכשל: שגיאה ברורה וקוד יציאה 1) |

כל הפקודות רצות משורש הריפו, למשל `python wa-status/wa_status.py test`.

## הגדרות — `config.json`

הקובץ נוצר מ-`config.example.json` בזמן `setup`, והוא לא נכנס ל-git.

| מפתח | משמעות |
|---|---|
| `phone` | המספר בפורמט בינלאומי בלי `+`, למשל `9725XXXXXXXX`. אם הוא ריק, הוא יתמלא אוטומטית ב-`setup` |
| `progress_interval_minutes` | מרווח העדכון המחזורי בדקות |
| `daily_summary_time` | שעת הסיכום היומי, לרישום ב-Task Scheduler |
| `project_name` | דריסת שם הפרויקט. אם הוא ריק, נלקח שם תיקיית הריפו |
| `enabled` | `false` משבית את הכלי מיד |
| `dry_run` | `true` מדפיס את ההודעה במקום לשלוח |

## סיכום יומי ב-Windows Task Scheduler (בלי Claude)

מריצים פעם אחת ב-PowerShell משורש הריפו. מחליפים את `21:00` בשעה שהוגדרה ב-`daily_summary_time`, ואת `<repo>` בשם הריפו:
```powershell
schtasks /Create /SC DAILY /ST 21:00 /TN "wa-status daily <repo>" /TR "\"$((Get-Command python).Source)\" \"$PWD\wa-status\wa_status.py\" daily"
```
בדיקה: `schtasks /Run /TN "wa-status daily <repo>"`. הסרה: `schtasks /Delete /TN "wa-status daily <repo>" /F`.

## כשל בשליחה

- כל כשל נרשם ב-`wa-status/state/wa_status.log`. הפקודות `send`, `summary` ו-`daily` מחזירות תמיד קוד יציאה 0, כדי לא לעצור את העבודה.
- אם ה-session פג או ש-`setup` לא הורץ, נוצר הקובץ `wa-status/state/failed.flag`. מריצים `setup` מחדש, והדגל נמחק כשההתחברות מצליחה.

## אבטחה ופרטיות

- **התיקייה `session/` מחזיקה את החיבור לחשבון שלך** (וגם רשימת אנשי קשר מהסנכרון). אסור לשתף אותה או להעלות אותה ל-git. מי שמחזיק אותה יכול לשלוח הודעות בשמך.
- לפני כל שליחה הכלי מסנן מההודעה מילים כמו token, password ו-key יחד עם הערך שאחריהן, שורות בסגנון `.env`, מחרוזות שנראות כמו טוקן, ונתיבים מלאים.

## סיכונים

- neonize היא ספרייה **לא רשמית**. השימוש בה מפר את תנאי השימוש של וואטסאפ, ויש סיכון שהמספר ייחסם. כל עותק של הכלי בריפו נוסף מוסיף עוד מכשיר מקושר, ומגדיל את הסיכון. כדאי לשקול מספר ייעודי.
- עדכונים תכופים מאוד מגדילים את הסיכון לחסימה.
- הודעה ל"הודעה לעצמי" נשלחת מאחד המכשירים המקושרים שלך, ולכן ייתכן שהטלפון לא יקפיץ עליה התראה.
