הבסיס של MongoDB

מבוא למתחילים מאפס, בלי שום ידע קודם במסדי נתונים.

1. מה זה מסד נתונים בכלל?

מסד נתונים הוא מקום שבו תוכנה שומרת מידע לאורך זמן, כדי שהמידע לא ייעלם כשסוגרים אותה.

לדוגמה: אפליקציה של חנות צריכה לזכור מי המשתמשים, אילו מוצרים יש ומה כל אחד הזמין. כל זה נשמר במסד נתונים.

MongoDB הוא אחד ממסדי הנתונים הפופולריים בעולם. הוא שומר את המידע בצורה של מסמכים, שנראים כמו כרטיסיות מידע.

2. הדימוי: ארון תיקים

הדרך הכי קלה להבין את MongoDB היא לדמיין ארון תיקים במשרד:

🗄️ Database (מסד נתונים): הארון כולו. למשל, ארון של "החנות שלי".
🗂️ Collection (אוסף): מגירה בארון. מגירה אחת למשתמשים, מגירה אחרת למוצרים.
📄 Document (מסמך): כרטיס אחד בתוך המגירה. כרטיס אחד לכל משתמש.
✏️ Field (שדה): שורה אחת על הכרטיס, עם שם וערך. למשל: שם = דני.
כלומר: בארון יש מגירות, בכל מגירה יש כרטיסים, ועל כל כרטיס כתובים פרטים.

3. איך נראה מסמך?

מסמך הוא אוסף של זוגות: שם השדה והערך שלו. הנה כרטיס של משתמש אחד:

{
  "name": "Dani",
  "age": 28,
  "email": "dani@example.com"
}

איך קוראים את זה:

  • הסוגריים המסולסלים { } מסמנים את ההתחלה והסוף של המסמך.
  • משמאל לנקודתיים נמצא שם השדה, ומימין להן הערך.
  • פסיק מפריד בין שדה לשדה.

סוגדוגמההסבר

מסמך עשיר יותר

{
  "_id": ObjectId("65a1f..."),
  "name": "Dani",
  "age": 28,
  "isActive": true,
  "hobbies": ["football", "guitar"],
  "address": {
    "city": "Tel Aviv",
    "street": "Herzl 10"
  }
}
  • _id: מספר זהות ייחודי שכל מסמך מקבל אוטומטית. לא צריך ליצור אותו לבד.
  • hobbies: רשימה של תחביבים.
  • address: כתובת, שהיא בעצמה מסמך קטן עם עיר ורחוב.
גמישות: לא כל הכרטיסים באותה מגירה חייבים להיות זהים. למשתמש אחד יכול להיות טלפון, ולאחר לא. זה אחד היתרונות הגדולים של MongoDB.

4. ארבע הפעולות הבסיסיות

כמעט כל מה שעושים עם מסד נתונים הוא אחת מארבע פעולות:

פעולהמה היא עושהבארון התיקים
➕ הוספהיצירת מסמך חדשמכניסים כרטיס חדש למגירה
🔍 חיפושמציאת מסמכיםמחפשים כרטיס במגירה
✏️ עדכוןשינוי מסמך קייםמתקנים פרט על כרטיס
❌ מחיקההסרת מסמךזורקים כרטיס

הפקודות כותבים ב-mongosh, חלון הפקודות של MongoDB. בכל פקודה, db.users פירושו: "במגירה של המשתמשים".

➕ הוספה

use myShop    // open (or create) the "myShop" cabinet

db.users.insertOne({ name: "Dani", age: 28 })

db.users.insertMany([
  { name: "Ruti", age: 32 },
  { name: "Yossi", age: 19 }
])

insertOne מוסיף כרטיס אחד, ו-insertMany מוסיף כמה כרטיסים בבת אחת. אם המגירה עוד לא קיימת, היא נוצרת אוטומטית.

🔍 חיפוש

db.users.find()                       // show all users
db.users.find({ name: "Dani" })       // users named Dani
db.users.find({ age: { $gt: 20 } })   // users older than 20
db.users.findOne({ name: "Ruti" })    // just the first match

בתוך הסוגריים כותבים מה מחפשים. סוגריים ריקים מחזירים את כל הכרטיסים.

✏️ עדכון

db.users.updateOne(
  { name: "Dani" },        // which document
  { $set: { age: 29 } }    // what to change
)

החלק הראשון אומר איזה כרטיס לעדכן, והחלק השני אומר מה לשנות. הפקודה $set פירושה "קבע ערך חדש".

❌ מחיקה

db.users.deleteOne({ name: "Yossi" })
⚠️ שים לב: deleteMany({}) עם סוגריים ריקים מוחק את כל המסמכים במגירה.

5. איך מתחילים לתרגל?

  1. פותחים חשבון חינמי ב-MongoDB Atlas. זה MongoDB בענן, בלי שום התקנה.
  2. מתקינים את MongoDB Compass, תוכנה גרפית שמראה את המגירות והכרטיסים בצורה ויזואלית.
  3. יוצרים מגירה, מוסיפים כמה כרטיסים ומתרגלים את ארבע הפעולות.
  4. לומדים בחינם באתר MongoDB University.

6. מה הלאה?

אחרי שארבע הפעולות ברורות, אלה הנושאים הבאים:

  1. חיבור מקוד: שימוש ב-MongoDB מתוך תוכנה שאתה כותב, למשל ב-Python או ב-JavaScript.
  2. Indexes: דרך לגרום לחיפושים לרוץ מהר, כמו אינדקס בסוף ספר.
  3. תכנון מסמכים: איך להחליט מה לשים באותו כרטיס ומה לפצל לכרטיסים נפרדים.
  4. Aggregation: חישובים על הרבה מסמכים יחד, כמו ממוצע גילאים או סכום הזמנות.
